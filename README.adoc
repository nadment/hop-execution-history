== Overview

An Apache Hop plugin that displays the execution history of pipelines and workflows. It adds
a chart to the pipeline and workflow editors showing past runs with their status and duration,
making it easy to spot trends, regressions, and failures over time.

== Main features

* Quick visual analysis: Instantly spot the failures
* Quick actions: a double-click opens the execution details.

image::doc/images/hop-execution-history.png[]

Each vertical column represents a specific execution of a workflow or pipeline. The bars at the top of the column indicate the overall duration and status of that execution (for example, green for success, red for failure).

Each horizontal line corresponds to an individual action or transformation. The icons at the intersection of a line and a column illustrate the status of that specific component.

== Requirements

* JDK 21
* Apache Maven 3.6.3 or higher
* Apache Hop 2.19.0 (see the `hop.version` property in `pom.xml`)

== Build

[source,shell]
----
mvn clean verify
----

The build produces `target/hop-execution-history-<version>.zip`, a ready to unpack Hop plugin
archive with the following layout:

----
plugins/misc/execution-history/
├── hop-execution-history-<version>.jar
└── version.xml
----

== Installation

`mvn clean install` unzips the archive into the Hop installation pointed to by the `hop.home`
property (`C:\hop` by default), under `custom/plugins/misc/execution-history`. Override it for
another installation:

[source,shell]
----
mvn clean install -Dhop.home=/opt/hop
----

For a manual installation, unzip `target/hop-execution-history-<version>.zip` into the `plugins`
folder of the Hop installation and restart Hop.
